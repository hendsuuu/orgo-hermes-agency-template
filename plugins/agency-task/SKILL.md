# Agency task contract

Start work only if the shared task record lists your agent ID as `Assigned
Agent` and its status is `Assigned` or `In Progress`. Update only your own task
status, progress, blocker, evidence, and delivery fields. Do not self-assign,
change another agent's assignment, or use a Telegram message as a substitute for
the task record.

Treat assigned work as a lease: announce `In Progress`, report a blocker quickly,
and move completed work to `Review` with the artifact and verification notes.
